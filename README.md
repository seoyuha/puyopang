# 잉글리시 뿌요 팡! 🟣🟡🔴

초등 6학년 영어 10·11·12단원과 6학년 주요 어휘·문장을 복습하는 **연결 퍼즐 대전 게임**이에요.
영어 문제를 맞히면 젤리 한 쌍을 받고, 같은 색 4개를 이어 터뜨리고, 2연쇄부터 상대에게 방해 젤리를 보내요.

## 주소
- 학생: `https://(주소)/` — 입장 코드 4자리 + 이름
- 교사: `https://(주소)/teacher.html` — 비밀번호는 그랑프리와 같아요 (Render 환경변수 `TEACHER_PASSWORD`로 바꿀 수 있어요)

## 그래픽 (네온 시안)
- 선생님이 주신 **puyo_neon_graphics_originals** 시안으로 첫 화면부터 모든 화면을 바꿨어요.
  - 학생: 첫 화면 → 입장 → 대결 대기실(2인전·3인) → 대결(2인전·3인) → 결과 → 오답 복습 → 랭킹, 게임 방법(2쪽: 기본 규칙 + 이벤트)
  - 교사: 로그인 → 교사 관리(경기 운영) → 랭킹 → 문제 관리 → 학습 기록 → 반 설정 → TV 실시간 모니터
- 화면은 시안 크기(1672×941) 그대로 무대를 만들고 기기 크기에 맞게 늘리거나 줄여요. 태블릿·휴대폰은 **가로**로 써요(세로면 돌려 달라는 안내가 떠요).
- 뿌요 6종 동작, 회전 버튼(최신 시트), 카운트다운·정답·연쇄, 아이템·이벤트 아이콘, 이벤트 배너, 승패, 경기 상태 알림, 운영 알림을 시트에서 잘라 `public/img`에 넣었어요.
- 시안을 고치면 `python3 tools/slice_graphics.py <원본 폴더>` 로 다시 잘라 넣을 수 있어요 (Pillow·numpy·scipy 필요).
- 칸이 정해진 표(랭킹 6줄, 기록 5줄 등)는 ◀ ▶ 쪽 넘김으로 보여 줘요. 시안에 없던 설정(문제 유형·10분 경기·방해 상한·AI 채우기·오답 다시 내기)은 교사 관리의 **세부 설정**에 있어요.

## 수업 흐름
1. **6학년 8반·9반·10반**이 처음부터 만들어져 있어요. 입장 코드는 **0608 · 0609 · 0610**으로 고정이라 서버가 다시 켜져도 바뀌지 않아요. 반이 더 필요하면 '새 반 만들기'로 추가해요.
2. **경기 설정**(2인전/3인전, 단원, 문제 유형, 시간, 색 수)을 고르고 **모두 자동 배정하고 시작**. 학생은 고를 것 없이 들어오기만 하면 돼요.
3. 늦게 온 학생도 자동으로 배정돼요. 짝이 맞지 않으면 AI와 대결하고, **AI전도 똑같이 랭킹 점수**에 들어가요.
4. 경기가 끝나면 결과·오답 복습·익힌 표현을 보며 기다리다가 **10초 안에** 다음 상대(또는 AI)와 자동으로 붙어요. 같은 상대와 연달아 붙지 않게 해요.
5. **랭킹** 탭: 우리 반 / 학년 전체 / 반 대항전. **TV 모드**로 큰 화면에 띄우기.
6. **기록** 탭: 많이 틀린 문제 TOP 10, 학생별(익힌 표현 수 포함)·경기별 기록 엑셀 내려받기.
7. 문제 관리(켜기·끄기, 엑셀로 추가)는 교사 화면에서만 해요.

## 랭킹전 (1:1)
- 교사 관리 → 경기 설정 제목 옆 **랭킹전 켜짐/꺼짐** 버튼으로 켜고 꺼요 (켜면 항상 2인전, 끄면 다시 자동 배정). 도전이 정해지면 학생 화면에 **랭킹전 VS** 화면이 5초 떠요.
- 학생은 대기실·결과 화면의 **우리 반 랭킹**에서 도전 상대를 골라요. 순위는 랭킹 점수 → 정답률 → 경기 수 → 먼저 들어온 순서로 한 줄로 세워요(같은 순위 없음).
  - 나보다 **위 순위**인 친구에게만 「도전!」 버튼이 생기고, 아래 친구는 🔒. **1위는 버튼이 없어요**(도전자를 기다려요).
  - 두 사람이 모두 기다리는 중이면 바로 대결, 상대가 경기 중이면 끝나자마자 대결해요. 도전받은 친구에게는 알림이 가고, 반 전체에 "5위 ⚔ 2위 랭킹전 시작!" 소식이 떠요.
  - 20초 동안 아무도 고르지 않은(도전 신청도 없는) 학생은 자동으로 짝을 지어 줘요(짝이 없으면 AI). 그래서 기다리기만 하는 학생이 생기지 않아요.
- 보너스: **도전 성공 +10점**, **방어 성공 +5점**. 기록·엑셀에 랭킹전 여부와 보너스, 학생별 도전 성공·방어 성공이 남고, 칭호 ⚔️도전왕이 생겨요.

## 경기 시간
- 3분 · 5분 · **데스매치**(교사 관리 화면), 7분 · 10분은 세부 설정.
- 데스매치는 시간 제한 없이 한 명이 남을 때까지 해요. 1분 30초에 피버 타임, 5분이 지나면 공격 2배로 끝을 앞당겨요(안전장치로 30분이면 점수로 끝).

## 규칙 요약
- 문제 푸는 동안 게임판은 멈춰요. 정답 → 젤리 한 쌍, 오답 → 힌트 보고 재도전(재도전 정답도 젤리 지급)
- 첫 시도 정답 ★1 · ★2 색 바꾸기 · ★3 방해 젤리 6개 지우기
- 2연쇄부터 공격. 받은 방해 젤리는 대기하다가 내 연쇄가 끝난 뒤 떨어지고, 내 연쇄로 먼저 상쇄돼요.
- 셋째 칸 맨 위(✕)가 막히면 탈락. 시간이 끝나면 살아남은 학생 중 게임 점수로 순위.
- **랭킹 점수** = 첫 시도 정답 3점 + 재도전 정답 1점 + 순위 점수(1등 20 · 3인전 2등 8 · 그 밖 3). AI전도 똑같이.

## 문제와 반복 학습
- 유형: 단어 뜻 · 뜻 보고 단어 · 그림 보고 단어 · 문장 뜻 · 뜻 보고 문장 · 문장 빈칸 · 알맞은 응답 · 문장 조립 (듣기 문제 없음)
- 기본 552문제, 낱말·문장 256개. 10·11·12단원은 그랑프리와 같은 표현, **6학년 종합**은 인사·날짜·날씨·길 찾기·외모·과거 경험·계획·장래 희망·건강·비교·횟수·허락 표현.
- **반복 학습**: 학생마다 낱말·문장별로 기록해서 틀린 표현은 자주, 처음 보는 표현은 보통, 두 번 이상 첫 시도에 맞힌 표현(익힌 표현)은 가끔 나와요. 같은 표현도 모양을 바꿔(단어 뜻 → 뜻 보고 단어 → 그림 / 문장 뜻 → 뜻 보고 문장 → 문장 조립) 다시 물어요. 틀린 표현은 같은 경기에서 3문제 뒤에 한 번 더 나와요.
- 교과서와 다른 문제는 **문제 관리**에서 끄고, 엑셀 양식으로 새 문제를 올리세요. (모든 반이 같이 써요)

## 기록 지키기
Render 무료 서버는 한동안 쓰지 않으면 잠들고, 깨어날 때 저장 파일이 지워질 수 있어요.
교사 화면이 1분마다 기록을 **그 컴퓨터 브라우저에 자동 백업**하고, 서버가 비어 있으면 로그인할 때 되살릴지 물어봐요.
수동으로 `기록 백업 내려받기` / `백업 불러오기`도 있어요.
